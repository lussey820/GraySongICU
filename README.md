# GraySongICU

**把 B 站、苹果播客、小宇宙里的声音，补进你的网易云音乐云盘。**

网易云「灰歌补全器」桌面版：歌单里因版权或 VIP 变灰的歌，用其他音源的同一首歌补进云盘，原歌单里就能正常播放。所有处理都在你自己的电脑上完成。

- 官网：<https://lussey820.github.io/graysongicu-site/>
- 下载：<https://github.com/lussey820/GraySongICU/releases>
- 问题反馈：<https://github.com/lussey820/GraySongICU/issues>

> 仅供技术学习与个人使用：上传内容仅限本人收听，请遵守网易云音乐、哔哩哔哩等平台的用户协议与版权法规，不要用于商业用途或二次传播。

## 这是什么

网易云歌单里灰掉的歌，通常是**平台没有版权或需要 VIP**。这个工具会：

1. 扫描你的「我喜欢的音乐」和自建歌单，找出变灰且云盘里也没有的歌曲；
2. 去 B 站、苹果播客等音源找到同一首歌的音频；
3. 下载后上传到你的**网易云音乐云盘**。

云盘里的歌可以正常播放，也可以批量收藏进自建歌单。它不修改平台版权状态，只是把你自己的音频放进你自己的云盘。

## 下载与安装（Windows 10 / 11）

- 安装包：`GraySongICU-Setup.exe`（最新版见 [Releases](https://github.com/lussey820/GraySongICU/releases/latest)），约 104MB，双击按向导安装即可（支持自定义安装目录）
- 免安装：`GraySongICU-Portable.exe`（单文件便携版，不写注册表，可放 U 盘）；或 `GraySongICU-<版本>-win.zip`（解压即用）
- 下载后可用 Release 页公布的 SHA256 校验安装包完整性
- 安装器会提示「基础包不包含离线补歌词（约 150MB）」，可现场勾选，首次启动自动下载；也可以稍后在应用内安装
- 安装包**未做代码签名**，首次运行 Windows 可能提示「未知发布者 / SmartScreen 已阻止」，点「更多信息 → 仍要运行」即可
- 如果检测到已安装过，安装器会提示「您已安装过啦」，可选择覆盖安装或退出

安装完成后从桌面快捷方式或开始菜单启动 `GraySongICU`。

## 扫码登录

打开应用后，点右上角**「账号」**：

- **网易云音乐**：点「扫码登录」，用网易云音乐 App 扫码，用于读取歌单和上传云盘
- **B 站**：点「扫码登录」，用哔哩哔哩 App 扫码，用于获取音源（不登录也能用，登录后音质更稳定）

扫码成功后，登录凭据会用 Windows 系统加密（DPAPI）保存在本机，明文不落盘、不上传。

> 扫码失败时，可以展开「手动粘贴登录凭证」，按提示从浏览器 Cookie 里复制 `MUSIC_U` / `SESSDATA`。这是备用方案，正常情况用扫码就行。

## 三步开始

1. **登录**：按上一节扫码登录网易云（B 站可选）
2. **找歌**：回到首页，粘贴 B 站视频链接 / BV 号、苹果播客单集链接、小宇宙单集链接，或直接选择「扫描歌单」
3. **上传**：选择音质（最高 / 192k / 132k / 64k，不可用时自动降级），点上传，进度和日志会实时显示

上传完成后云盘列表自动刷新，可直接在列表里播放或删除。超过 200MB 的文件会先询问是否拆分。

## 支持的音源

| 音源 | 用法 | 说明 |
|---|---|---|
| B 站 | 视频链接 / BV 号 / 搜索结果 | 主要音源；音乐、评书、戏曲、助眠内容都在这里找 |
| 苹果播客 | 节目或单集链接 | 播客优先从这里取 |
| 小宇宙 | 单集链接 | 直接粘贴单集链接即可 |
| 通用直链 | 任意音频直链 | 自动检查大小后下载并上传 |

内容类型不绑定音源：音乐、评书、戏曲、播客、助眠都能处理。

## 主要功能

- **灰歌诊断**：先标出最该补的歌，按歌单批量处理
- **多 P / 合集**：自动展开分 P 与合集，逐个上传，失败自动重试不中断
- **草稿式命名**：自动识别歌曲名、歌手，可手动指定
- **云盘批量收藏**：勾选云盘歌曲，一次加入自建歌单（不改动他人歌单）
- **桌面歌词**：独立浮窗显示当前播放，可拖动、置顶
- **离线补歌词**：给没有时间轴的音频用本地 Whisper 生成时间戳（需额外下载约 150MB 组件）
- **流式上传**：下载与上传全程边写边传，200MB 以内的文件不整块读进内存
- **内嵌 ffmpeg**：装好即用，不需要自己配环境
- **上传历史**：本地记录，重复上传会提示
- **重启更新**：每天早上 7 点自动检查一次，有新版本时按钮显示小红点；点击后自动下载、校验并静默安装，随后自动重启应用

## 常见问题

**会上传我的登录信息吗？**
不会。登录信息只保存在你自己的电脑上，且经过系统加密，不会传到任何服务器；程序也只在本机运行。

**支持哪些音源和内容类型？**
音源为 B 站、苹果播客；小宇宙单集链接也能直接用，不新增平台。内容类型包括音乐、评书、戏曲、播客、助眠；评书、戏曲、助眠在 B 站搜索，播客优先苹果播客。

**为什么有些歌传不上去？**
常见原因是文件太大或登录过期。超过 200MB 会询问是否拆分；登录过期会提示重新登录，不会留下上传了一半的文件。

**会触发平台风控吗？**
上传时会自动放慢节奏，失败也会重试；仍建议一次不要选太多，所有功能仅用于本人收听。

**需要网易云会员吗？**
不需要会员，但需要账号有云盘容量。VIP 专属歌曲只是从其他音源补进云盘，不改变原歌单的版权状态。

**需要额外安装东西吗？**
不用。上传、搜索、看歌词都不需要额外安装；只有离线补歌词需要一次性下载组件，不装也不影响其他功能。

**和 Melody / NeteaseCloudMusicApi 有什么区别？**
那些项目基于旧的 weapi 通道，2025 年后基本失效且原仓库已删库。本项目是当前客户端 eapi 协议的独立实现（云盘操作走 `interface.music.163.com`），并且是带界面的桌面应用。

## 隐私与安全

- 服务只监听 `127.0.0.1`，不暴露到局域网，外部设备无法访问
- 登录凭据用 Windows DPAPI 加密保存（`%APPDATA%\GraySongICU\cookie.enc`）
- 上传历史、歌词索引只存在本地，可用设置里的清除功能删掉
- 下载与上传均为本机直接连接平台接口，不经过第三方中转

## 系统要求

- Windows 10 / 11（x64）
- 安装包约 104MB；运行内存建议 4GB 以上
- 网络需能访问 B 站、苹果播客与网易云音乐接口

## 开发者附录

单文件 Node 服务 + Electron 外壳，零第三方运行时依赖：


```
bin/ffmpeg.exe     # 内嵌转码工具（不入库，构建时打包）
```
